# Sentiment Analysis on Product Reviews

## Project Overview

This project performs sentiment analysis on Amazon Fine Food product reviews using Natural Language Processing (NLP) techniques. The objective was to classify customer reviews into Positive, Negative, and Neutral sentiments and generate meaningful business insights through visualization and polarity analysis.

## Business Objective

E-commerce platforms receive thousands of customer reviews daily. Manually analyzing customer feedback is inefficient and time-consuming. This project demonstrates how NLP and sentiment analysis can help businesses automatically understand customer satisfaction patterns and identify areas of concern.

## Tools & Technologies

- Python
- Pandas
- TextBlob
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Features

- Data Cleaning & Preprocessing
- Sentiment Classification
- Polarity Score Analysis
- WordCloud Visualization
- Review Length & Word Count Analysis
- Sentiment Distribution Charts
- Business Insights & Recommendations

## Key Insights

- Most customer reviews were positive, indicating strong overall customer satisfaction.
- Negative reviews frequently mentioned delivery delays and packaging issues.
- Reviews with higher polarity scores generally aligned with higher product ratings.
